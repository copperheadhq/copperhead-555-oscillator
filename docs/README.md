# Documentation

The design documents of the 5 V Variable-Frequency 555 Oscillator at rev A (release commit `c822784`, design at `6d0c6c8`), published as they were written alongside the design.

| File | What |
| --- | --- |
| `BRIEF.md` | the brief the design was built from, unedited |
| `BOM.md` | design document from the workspace, unedited. Every MPN is still marked UNVERIFIED |
| `CHANGELOG.md` | design document from the workspace, unedited |
| `DECISIONS.md` | design document from the workspace, unedited |
| `PINOUT.md` | design document from the workspace, unedited |
| `SPEC.md` | design document from the workspace, unedited |
| `SUBSYSTEMS.md` | design document from the workspace, unedited |
| `BOARD-STATS.md` | measured board statistics: parts, pads, holes, vias, track widths, pours, DRC and ERC |
| `schematic.pdf`, `schematic.svg` | the schematic, exported from `hardware/` with KiCad 10.0.6. Regenerate rather than edit |

These documents record choices as they were made, and name files that are not in this repository: `outputs/`, `openspec/`, `releases/`, `research/`, `docs/LAYOUT.md`, `docs/DEVPLAN.md`, `docs/parts.intent.json` and `.copperhead/constraints.json`. The rev A fabrication files from `releases/rev-a/` are in [`../fab/rev-a/`](../fab/rev-a/).
